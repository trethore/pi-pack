# pi-openai-settings

Manage advanced OpenAI Responses settings.

## Installation

Requires Pi `1.6.1` or a compatible later release.

From the repository root, install pi-openai-settings globally:

```bash
npm ci
npm run build
npm run install:pi-openai-settings
```
