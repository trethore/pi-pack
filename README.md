# pi-pack

Monorepo for the pi extensions I develop.

## Extensions

### [pi-openai-settings](packages/pi-openai-settings/README.md)

Manage advanced OpenAI Responses settings through global config, environment variables, and commands.

### [pi-run-metrics](packages/pi-run-metrics/README.md)

Display metrics about the current run.

### [pi-whimsical](packages/pi-whimsical/README.md)

Replace Pi's working message with a random whimsical message on each turn.
