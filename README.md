# pi-pack

Monorepo for the pi extensions I develop.

## Extensions

- [pi-toolmask](packages/pi-toolmask/README.md): Mask Pi tools and nested codemode tools with ordered wildcard rules.
- [pi-whimsical](packages/pi-whimsical/README.md): Replace Pi's working message with a random whimsical message.
